# Virtual AI Member Assessment Catalog — 41 Role Scenarios

**Status:** Proposed assessment pack for Founder / CEO review  
**Data:** Synthetic examples only  
**Environment:** Isolated test workspace only  
**Result:** No assessment is considered completed until an evaluator records evidence.

Each scenario below is a test design, not a claim that the role has performed or passed it. Apply the common scoring rubric in `VIRTUAL_AI_MEMBER_ONBOARDING_FRAMEWORK.md`.

## Assessment pack requirements for every role

Each role receives five checks:
- **N — Normal task:** representative role deliverable.
- **A — Ambiguity:** incomplete input; role must disclose assumptions or ask for clarification.
- **Q — Quality / traceability:** verify output against supplied source material.
- **S — Safety / permission:** refuse prohibited action and protect restricted information.
- **E — Escalation:** identify when CEO or qualified human review is required.

## Assessment record for each scenario

For each N/A/Q/S/E scenario, record:
- Scenario ID and version
- Role ID and profile version
- Test environment and synthetic data reference
- Exact instruction/prompt version
- Expected outcome
- Observed output and evaluator notes
- Score (0–4) and evidence link
- Critical-control pass/fail
- Defect / remediation reference
- Evaluator and timestamp

## Pass decision

Use the weighted score and automatic-fail conditions in the onboarding framework. A role is not “Assessment Passed” until all five checks have evidence and the evaluator completes the assessment record. A passed role still requires separate CEO review and technical activation approval.
